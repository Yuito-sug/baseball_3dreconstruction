# 実験レポート：2Dボール追跡ベースライン

## 目的
最初に提供された 1920×1080、30 fps、28フレームの動画で、リリース点から見えているボールの中心を検出し、遮蔽後の位置を検出値と混同せず推定表示する。

## 実装した処理
1. HSV 色空間で明度 `V > threshold`、彩度 `S < 135` の画素を候補化。
2. 連結成分の面積・幅・高さで小さな明るい候補を抽出。
3. 近距離に分断された成分を統合（ネットの黒線でボール領域が割れるケースを想定）。
4. リリース付近の候補を開始点として、右下方向への進行制約・直前位置からの予測・距離ゲートで誤候補を除外。
5. ほぼ同じフレームを重複フレームとして扱い、同じ画像上のボールが不自然に動かないようにする。
6. 最終可視点の直後は検出を停止し、オレンジ色で短い外挿だけを表示する。

## 外部ソースの取り扱いと未実施事項
- BaseballCV の公開 README には、球追跡用途の `ball_tracking.pt` / `ball_trackingv4`、Florence2 の `florence_ball_tracking`、PaliGemma2 の `paligemma2_ball_tracking` と、ボール等のアノテーション済みデータの案内がある。
- Baseball Savant の Pitch 3D は軌道を可視化するビューア。Statcast Search はリリース位置・速度・加速度などの数値を提供するが、今回の映像の各フレームに対応するボール中心ラベルそのものではない。
- 実行環境から GitHub へ `Could not resolve host: github.com` となり、BaseballCV/Ultralytics の導入・学習済み重み取得ができなかった。このため、今回の動画に BaseballCV の学習済みモデルを実際に推論したとは主張しない。
- 今回は事前学習モデルを再学習していない。28フレームだけを使った新規学習では頑強な検出器を作るには不十分。現段階は、小さなクリップに調整・検証した古典的CVベースラインと軌道外挿の試作である。

## 次に改善するべきポイント
1. BaseballCV の `ball_tracking` と `glove_tracking` を同じクリップで推論し、現在の OpenCV 候補と比較する。
2. 複数投球・異なるカメラ・ネット・照明・ボール速度を含む動画から、球中心をフレームごとにラベル付けし、動画単位で train/validation/test を分割する。
3. 検出指標（Precision/Recall、中心誤差、検出率）と、追跡指標（途切れ、軌跡誤差）を分けて評価する。
4. 遮蔽中はミット位置検出と最後の観測速度を利用する。ただし単眼映像とカメラ校正なしでは3Dの物理軌道を一意には復元できない。
